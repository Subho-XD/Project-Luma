# Project Luma v3.3.0 — Known Limitations

1. **RDNA 2 (`AMD Radeon RX 6600 / gfx1032`) HIP SDK 7.2 Support:** AMD's official Windows HIP SDK 7.2 documentation excludes `gfx1032`. On the verified RX 6600 test system (`Adrenalin 26.11.2`), `amdhip64_6.dll` (`10.0.3652.0`) initializes cleanly while `amdhip64_7.dll` is absent. Experimental RDNA 2 Neural Rendering execution depends on upstream `DLSS-NR-on-AMD v0.9.0` runtime compatibility and user-supplied components.
2. **DLSS Frame Generation Unavailable on RX 6000:** Per `DLSS-NR-on-AMD v0.9.0` release notes, DLSS Frame Generation does not work on RX 6000 (`RDNA 2`) GPUs. Project Luma disables that backend choice on RX 6000 and recommends native FG, `OptiFG DX12 + HUDfix`, `AMD FSR Frame Generation 4.0.2`, or Adrenalin AFMF 2 instead.
3. **No Auto-Bundling of Restricted Third-Party Binaries:** Project Luma never bundles, mirrors, or silently modifies `NeuralHub_v0.9.0_setup.exe` or proprietary NVIDIA DLLs (`nvngx_dlssnr.dll`, `nvngx_dlss.dll`, `nvngx_dlssg.dll`). Without an installed `NeuralHub` runtime and a user-supplied `nvngx_dlssnr.dll` (`>= 310.9.16.0` for CC or `>= 310.8.0.0` for HT), `AI Visuals` cannot deploy or activate.
4. **Unsigned NVIDIA / Local DLLs Offline:** Windows Authenticode chain checks require either embedded certificates or trusted root certificates. Files lacking an embedded signature are flagged clearly as `Signature verification unavailable` rather than silently treated as publisher-signed.
5. **DX11 / Vulkan OptiFG Injection:** In-app Frame Generation injection supports DirectX 12 (`OptiFG DX12`) only. DirectX 11 and Vulkan titles without native FG are guided to driver-level **AMD Adrenalin AFMF 2**.
6. **Kernel Anti-Cheat Games Blocked by Default:** Games protected by kernel anti-cheat (e.g., `PUBG: BATTLEGROUNDS`, `VALORANT`) are never injected unless an officially supported offline single-player mode is explicitly confirmed.
7. **Manual Custom Root Folder Scanning:** Adding a broad top-level utility/games directory (e.g. `F:\Games`) scans immediate `.exe` subfolders blindly and can surface non-game launcher stubs located inside that folder unless added individually or placed cleanly per game folder.
8. **Live 3D Rendering / FPS Not Captured Automatically:** Project Luma v3.3.0 verifies static PE imports, `OptiScaler.ini` serialization, health checksums, and SHA-256 rollbacks directly on disk, whereas live in-game FPS gains and visual quality in full 3D gameplay remain up to per-title visual verification by the user.
