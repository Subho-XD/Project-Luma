# Project Luma — Bug Register & Root-Cause Resolutions

| Bug ID | Severity | Component | Root Cause Identified | Verification & Fix Applied |
|---|---|---|---|---|
| **BUG-01** | **Critical** | `GitHubPackageManager.cs` (`Download Official` hang/crash) | `HttpClient.Timeout` (`30s`) aborts `70.4 MB` `.7z` streams on normal links; `ExtractSevenZipSafely` uses `foreach (var entry in archive.Entries)` causing solid LZMA2 re-decompression on every file; file extraction & hashing ran inline without `Task.Run` offloading. | Increased stream client timeout to `15m` with `20s` metadata connect timeout; switched `.7z` extraction to forward-only single-pass `archive.ExtractAllEntries()`; offloaded extraction & SHA-256 to background threads; added `.part` resume and exponential retry backoff. |
| **BUG-02** | **High** | `MainViewModel.cs` / `BackendModels.cs` | Concurrent clicks could spawn overlapping downloads for the same backend; no live progress %, MB count, speed (MB/s), cancel token cleanup, or `Retry`/`Cancel` recovery UI. | Added per-backend `SemaphoreSlim` locks, `ComponentInstallState` enum (12 states), throttled streaming progress callbacks, cancellation `.part`/`.tmp` cleanup, and Retry/Cancel UI controls. |
| **BUG-03** | **High** | Branding & Icons (`Icons.xaml`, `.csproj`) | Application and installer used `IconPrism` triangular vector logo and lacked multi-resolution Windows `.ico` branding. | Replaced all icons with exact user-supplied `Luma_Icon.svg` / `Luma_Icon.png` white ghost on `#ED1C24` square and multi-size `.ico` (`16–256px`). |
| **BUG-04** | **High** | Typography & Color Theme (`LumaTokens.xaml`) | Used `Space Grotesk` + `Manrope` + cyan `#38BDF8` palette across main app and installer. | Removed `Space Grotesk`; bundled official Google Fonts `GoogleSans.ttf` + `SpaceMono-*.ttf` (SIL OFL-1.1); shifted theme completely to AMD red (`#ED1C24`), black (`#101010`), and charcoal (`#181818`/`#202020`/`#292929`). |
| **BUG-05** | **High** | Launching & Overlay (`GameInstaller`, `UI`) | No `PLAY` button, store protocol launch, running-process guard, or optional click-through launch notification. | Added `GameLaunchService` (Steam URI + verified exe launch) and Win32 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE` `LumaLaunchOverlayWindow` reporting only verified active integrations. |
| **BUG-06** | **Medium** | `CapabilityEngine` & `UserDllVault` | RX 6600 target string `gfx1032` and official HIP 7.2 exclusion weren't surfaced explicitly; CC model `>= 310.9.16.0` build check and automatic game-folder DLL discovery were missing. | Added `GpuTarget` (`gfx1032`), `Hip72OfficiallySupported`, `SupportsCcModel` check (`>= 310.9.16.0`), and scoped `ScanGameLibrariesForUserDllsAsync`. |
| **BUG-07** | **Medium** | Onboarding (`MainViewModel`, `MainWindow`) | 6-step onboarding felt overly technical to first-time PC gamers. | Redesigned into 3 clean steps (`Meet Project Luma`, `Find Your Games`, `Ready to Play`) with immediate SQLite persistence (`HasCompletedOnboarding`). |
| **BUG-08** | **High** | Setup & Uninstaller (`ProjectLuma.Setup`) | Blue 5-screen wizard; uninstall relied on a plain `uninstall.bat` without Windows `Installed Apps` registration, repair UI, or selective backup/game-restoration options. | Rebuilt into 3-stage AMD-red Setup (`Welcome`, `System Check`, `Install & Finish`), added `UninstallWindow` maintenance UI, registered `HKCU\...\Uninstall\ProjectLuma`, and created Start Menu uninstaller shortcut. |
